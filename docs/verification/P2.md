# P2 extension and memory preview

Date: 2026-10-26. This delivers the three requested feature areas as a local preview. It does not close every gate in the wider P2 plan.

## Delivered and checked

Tests drive the native loop through skill loading, memory writes and MCP proposals, revoke skills on the next turn, and reopen sessions without repeating a memory mutation. Earlier chats retain their original runtime identities.
- **Skills:** YAML-frontmatter validation, project scope, disabled import/update/rollback, one previous revision, explicit enable/disable, export/delete, pinned content hash. Plain text rendering; no resource/script execution. A real pinned Hub skill passed the import/enable/load path.
- **MCP:** official SDK client with synthetic HTTP and real local stdio server round trips. Minimal child environment; explicit host trust; encrypted bearer/bridge token custody; bounded discovery and schema digests; separate server/tool grants; exact-call approval; intent-before-send and no retries; changed schemas block execution; network loss becomes unknown and blocks new calls. Reconciliation requires a recorded user explanation of the checked remote outcome. No duplicate external effect on reapproval.
- **Agent Zero bridge preview:** base URL + separate encrypted token + optional remote project, using Agent Zero's actual HTTP route shape. Token-bearing URLs are rejected at form/API input. Synthetic protocol/custody checks pass. No real owner-instance acceptance yet.
- **Plugin Hub:** actual generated catalog read (218 entries), exact-commit source trees, compatibility reasons/date/revision, current unknown entries for missing pins, last-good cache and stale-response protection, review/import individual Markdown skill. Python/UI plugin routes are never installed natively.
- **Memory:** SQLite/FTS5 project isolation, familiar areas, explicit recall/write policy, source provenance, manual edit/save/delete, text export/import, transactionally deduplicated writes/deletes, active vector/FTS deletion and retention disclosure. Injected receipt failure rolls back the entire text/search/receipt mutation. Schema 3 backs up prior data before migration; users can inspect/delete whole migration backups explicitly.
- **Embeddings:** pinned MiniLM download/size/license, SHA-256 validation of all files, progress/pause/retry/deletion, actual local-only CPU inference in a worker. Separate compatible endpoint connections and encrypted credentials; explicit project text/query-sharing choice. Validated vector dimensions/finite values/norms, namespace fingerprint, incremental checked-vector reuse, source-generation validation, atomic activation, pause/restart handling, lexical fallback, hybrid rank fusion, revocation of hosted sharing by switching to lexical only.
- **UI:** desktop and mobile review of plain-title Skills & MCP, Plugin Hub and Memory views, with original Agent Zero art. Eyebrow labels and slogan-style copy removed throughout the app at the owner's request.

## Bounded subordinates and transcript/status follow-up — 2026-10-26

- New chats add a versioned `call_subordinate` tool. Separate child sessions share the project and model connection, receive only the assignment and current capability subset, and keep their own history. Child tools are file reads, enabled skills and permitted memory recall. No child writes, MCP, code execution or model/profile overrides.
- Persist the parent chat/message/execution ID to child mapping and child snapshot atomically before starting. Duplicate IDs join the running job or reuse its receipt. Changed arguments are rejected. A fresh model call cannot bypass an unresolved interrupted child by selecting another context.
- Fixed limits: depth two, two active assignments and six calls per root turn, eight model requests per assignment, two minutes or remaining parent time, and 16,000 returned characters. Requests share the persisted 40-request connection budget. No universal token/cost ceiling is claimed.
- A real SIGKILL of the synthetic native worker proves that reopening makes no model request, an old parent-turn replay does not recreate or rerun the child, and explicit continuation closes the abandoned turn and reuses that child. Parent cancellation propagates to descendants; a subsequent parent turn works. Native nested-call, repeat-ID, restart, budget, permission ceiling/revocation, direct-child ownership, depth/concurrency and deadline tests pass.
- Assistant Markdown uses pinned react-markdown/remark-gfm: bold, inline/fenced code, lists and tables, including streamed fragments and saved transcripts. Raw HTML and unsafe URL schemes are rejected. Images become explicit links rather than automatic external requests.
- Local environment state distinguishes configuration/last checked connection revision from active operations and unresolved cleanup. Changing credentials invalidates earlier verification. Polling local state every three seconds makes no provider request. The chat header identifies its frozen execution setting; cloud chat execution remains disabled.

## Cancellation and crash-recovery repair — 2026-10-26

Hosted macOS checks on `83405e1` exposed premature Stop completion and an intermittent child-continuation timeout; Linux passed that checkpoint. Local repeated SIGKILL checks reproduced both timing boundaries. Stop now aborts descendants immediately, waits for pending startup and tracked work, and blocks another turn while cancellation settles. A child still obtaining its session sends no model request after its parent is stopped.

Continuation blocks the old child's model transport and requires a terminal event for its exact previous message. The local libfx backend retains a killed writer's in-band lock for 30 seconds and retries acquisition for up to 35 seconds; the recovery allowance is now 40 seconds or the remaining assignment time. Unknown cleanup preserves the interrupted hold, including when a concurrent Stop occurs. A separate stored last-submitted message ID prevents failed continuation attempts from replacing the identity being reconciled.

Local evidence: **66 tests passed**, TypeScript and production build passed, and the dependency audit reported zero vulnerabilities on Node 24.22.1/macOS. The focused cancellation/recovery suite also passed **six consecutive runs**. Tests prove exact-message terminal matching, split stream chunks, timeout/unknown/abort holds, child startup cancellation, descendant settlement, no child inference on reopening, and explicit continuation using the same child with only the new assignment reaching the provider. These are synthetic native-runtime checks; hosted CI and live ChatGPT acceptance are separate receipts.
