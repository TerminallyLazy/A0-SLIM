# Local alpha verification — 0.1.0-alpha.1

Date: 2026-10-26. This is the delivered P1 subset, with outstanding P0/live gates retained explicitly. The [foundation record](P0.md) describes the earlier checkpoint.

## Delivered behavior

- ChatGPT registration and public Responses text/function bridge, full completed-output journal encrypted in the application vault, per-account/chat/model routing, terminal-success tool dispatch, safe error notices and bounded protocol storage.
- Reviewed artifacts: immutable destination/content digest, before/after preview, download, apply/reject, conflict review and restart reconciliation. Model tools only stage proposals. Paired browser actions apply them.
- Per-project/model/connection persistent 40-request/10-minute circuit breaker, including retries and shared across execution presets; 10-minute turn timeout; Stop and Redirect; visible stop notices.
- Schema 2 migration with a private pre-migration SQLite backup, preserved chats and exclusive service ownership.
- Optional local Docker Node.js execution, with project defaults frozen into new chats and effective environment displayed in the composer/inspector.
- Vercel, Modal, E2B and Daytona synthetic cloud checks, exact-resource recovery, credential forms, usage acknowledgment and source-linked free allowances. Their agent execution remains disabled pending real provider acceptance.

## Real ChatGPT account check

The owner connected ChatGPT through A0 SLIM's dedicated sign-in UI. No token file from another app was reused. With account-selected **gpt-6.1-sol**, the real service:

1. Read the public synthetic `examples/live-check/note.txt`.
2. Proposed `result.txt` through `write_file` and reached terminal success.
3. Displayed the exact artifact for review; an explicit UI application produced `Paper Garden\n`. SHA-256: `301d46494dc4c9de71b2085f02d8d2f0df4afff58ba293b4b974cb28d5c554e0`.
4. Read two synthetic files in a separate conversation, then restored both conversations after a full local-service restart. Follow-up requests returned `Paper Garden` with terminal success and no tools. The original artifact conversation also recovered after the bridge fix; its history was retained.

The first live stream exposed an empty terminal `output` array: completed output arrived in `response.output_item.done`. The bridge now buffers these records and releases them only after `response.completed`. Restart testing then exposed libfx's inserted file-evidence note; a native regression reproduces the same behavior, and the corrected bridge passed live continuation.

The app's own macOS Keychain key was verified available. A status-only protocol audit found no reasoning items in the initial successful live tool chain. **Live encrypted-reasoning output is not claimed.** Synthetic tests establish its preservation contract. Real refresh rotation, account switching, remote revocation and quota exhaustion still need controlled owner participation; do not deliberately exhaust subscription usage to simulate a quota error.

## Remaining acceptance

- Owner-run Vercel, Modal, E2B or Daytona check in **Environments**: confirm plan/remaining free allowance, enter credentials only in the app, acknowledge usage, then verify artifact and cleanup receipt. Vercel offers an additional stop/delete reconciliation action; Modal confirms terminated compute while app/image metadata may remain. No live cloud acceptance is claimed.
- Real ChatGPT reasoning-bearing output and controlled refresh/reconnect/revocation checks; broader model/tool capability tests. Compacted/changed history requires a fresh chat with a reviewed summary.
- AI Gateway's live wire path and installed Ollama/LM Studio models each require their own receipt. Generic compatible fixture tests do not prove these services.
- P1 is a local alpha, not a general shell/patch/filesystem product. Artifacts are bounded text replacements with existing parent directories; code gets explicit input and returns bounded output. Cloud transfer manifests, arbitrary cloud execution, editable budgets and richer presets remain target work.
- P2 memory, local embeddings/downloads, delegation, skills/MCP, Plugin Hub and third-party runner protocol remain planned. No public package release is implied by a Git push.
