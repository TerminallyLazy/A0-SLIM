# Agent Zero source artwork

Additional official artwork supplied by the owner on 2026-10-26. Files are copied unchanged from the reference checkout. Source-relative paths and SHA-256 hashes are in `sources.json`; the reference checkout remains read-only.

- `dark.svg`: square symbol and Agent Zero wordmark.
- `horizontal_banner.svg`: wide symbol and wordmark banner; also served unchanged as `ui/public/a0-horizontal-banner.svg` in Appearance.
- `banner.svg`: centered wordmark banner.
- `a0LogoVector.ai`: editable Illustrator source, retained for future brand work; not served by the app.

The existing symbol-only light/dark assets remain suitable for small navigation marks. These marks identify Agent Zero as the inspiration for A0 SLIM; they do not imply upstream endorsement. See the repository third-party notices and Agent Zero license.
